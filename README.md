This is a simple project about SDL use. 
It is still in it's early stage. 
I am working and aiming to learn SDL by working on this repo. 
To run this repo, you will need to download the SDL Library, which you can easily find a tutorial for on youtube. 
On WSL2 You can use "sudo apt update && sudo apt install libsdl2-dev libsdl2-image-dev libsdl2-ttf-dev libsdl2-mixer-dev -y" to install SDL2.
To run the code. Type make in the terminal followed by a make run.
